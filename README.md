# 인명용 한자 찾기

이름에 쓸 한자를 **정확히 같은 글자로** 가리키기 위한 보조 도구입니다.

👉 **https://sura140705-crypto.github.io/inmyeong-hanja/**

## 왜 만들었나

인명용 한자 9,000여 자 가운데 **442건은 유니코드에 코드포인트가 없습니다.**
대법원 시스템 안에서만 의미 있는 자체 코드로 관리되는 자형이라, 복사해서 주고받으면
다른 프로그램에서 모양이 깨집니다. 흔한 글꼴에 없어 두부(□)로 보이는 한자도 많습니다.

그래서 문자를 주고받는 대신 **양쪽이 같은 화면의 같은 번호와 같은 자형을 보게** 했습니다.

```
가-02 · 나-13
```

## 화면

| 경로 | 화면 | 내용 |
|---|---|---|
| `/` | 진입점 | 기기를 보고 알맞은 화면으로 이동 (수동 전환 가능) |
| `/simple.html` | **간편 조회** (모바일) | 한글음 입력 → 한자 고르기 → 선택번호 전달 |
| `/full.html` | **전체 조회** (PC) | 독음·뜻 검색, 별표 구분, 이체자 관계, 영문 자해 |

쓰는 사람의 신분이 아니라 기기와 정보량으로 나눴습니다. 간편 조회는 휴대전화
세로 화면에 맞춰 자형을 크게 보여주고, 전체 조회는 한 화면에서 전부 훑습니다.

## 선택번호

대법원 조회 서비스가 돌려주는 조회 순번을 그대로 씁니다. 489개 독음 전부
1..N 으로 연속임을 확인했고, 두 화면 모두 그 순서를 그대로 따릅니다.

**선택번호는 이 사이트의 안내번호이며 대법원이 부여한 공식 코드가 아닙니다.**

## 뜻(훈)에 대하여

훈은 참고정보입니다. 신고 가능 여부의 근거가 아닙니다.

| 표시 | 뜻 |
|---|---|
| 그냥 적힌 뜻 | `hanja.txt` 또는 Unihan 에서 확인된 훈 |
| `檟의 동자` 등 | 다른 글자에서 물려받은 훈. 그 사실을 함께 밝힙니다 |
| `[영문]` | 한국식 훈이 없어 Unihan 영문 자해만 있는 글자 (간편 조회) |
| `자동` | 위 영문을 기계번역한 **미검수** 참고값 (전체 조회) |
| `뜻 정보 없음` | 어느 자료에도 없음. 추측해서 채우지 않았습니다 |

10,381개 항목 중 훈이 확인된 것은 8,201건(79.0%)입니다. 나머지를 억지로
채우지 않고 없는 것은 없다고 적었습니다.
