# 인명용 한자 찾기

가족관계등록 창구에서 **민원인과 담당자가 같은 한자를 정확히 가리키기 위한** 보조 도구입니다.

👉 **https://sura140705-crypto.github.io/inmyeong-hanja/**

## 왜 만들었나

인명용 한자 9,000여 자 가운데 **442건은 유니코드에 코드포인트가 없습니다.**
대법원 시스템 안에서만 의미 있는 자체 코드로 관리되는 자형이라, 복사해서 주고받으면
다른 프로그램에서 모양이 깨집니다. 흔한 글꼴에 없어 두부(□)로 보이는 한자도 많습니다.

그래서 문자를 주고받는 대신 **양쪽이 같은 화면의 같은 번호와 같은 자형을 보게** 했습니다.

```
가-02 · 나-13
```

## 화면

| 경로 | 대상 | 내용 |
|---|---|---|
| `/` | — | 기기를 보고 알맞은 화면으로 이동 (수동 전환 가능) |
| `/minwon.html` | 민원인 | 한글음 입력 → 한자 선택 → 담당자에게 보여주기 |
| `/staff.html` | 담당자 | 전체 조회. 독음·뜻 검색, 별표 구분, 이체자 관계 |

민원인 화면은 휴대전화 세로 화면에 맞춰 이름을 세로로 세워 자형을 크게 보여줍니다.

## 선택번호

대법원 조회 서비스가 돌려주는 조회 순번을 그대로 씁니다. 489개 독음 전부
1..N 으로 연속임을 확인했고, 화면 정렬이나 필터를 바꿔도 번호는 흔들리지 않습니다.

**선택번호는 이 사이트의 안내번호이며 대법원이 부여한 공식 코드가 아닙니다.**

## 자료 기준

실제 신고 가능 여부와 정확한 자형은 가족관계등록 담당기관에서 최종 확인해 주세요.
